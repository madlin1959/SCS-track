# Weekly Audit
When to use: Every week before starting changes on a script or tool.
Steps:
1. Pull latest repo state and inspect workspace status.
2. Run existing tests to establish baseline pass/fail output.
3. Review recent changes or logs for obvious regressions.
4. Record findings in the audit note.
How you know it worked: Baseline test output and current audit notes match repo state.
