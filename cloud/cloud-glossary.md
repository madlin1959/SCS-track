# Cloud Glossary — SCS2b.1

| Term | In my own words | Found on — which screen |
|---|---|---|
| region | A main geographical area in the world where AWS places its physical data centers. | IAM Console top right bar |
| availability zone | A single, isolated data center located inside a larger AWS region. | EC2 Console launch screen |
| console | The main website control panel used to manage your cloud services. | AWS main dashboard screen |
| IAM | The service used to control who can log in and what they are allowed to do. | IAM Dashboard screen |
| user | An individual login account created for one specific person or tool. | IAM -> Users page |
| group | A collection of user accounts that all share the exact same permissions. | IAM -> User Groups page |
| policy | A written list of rules stating what actions are allowed or denied. | IAM -> Policies page |
| instance | A virtual server running inside the cloud provider's computer system. | Not yet (SCS2b.3) |
| bucket | A basic storage container used to hold files and media in the cloud. | S3 Management Console |
| security group | A virtual network firewall that blocks or allows traffic to a server. | Not yet (SCS2b.3) |
| key pair | A set of secret and public keys used to safely sign in to a server. | Not yet (SCS2b.3) |
| SSH | A command-line tool used to log into remote Linux servers safely. | Ubuntu-SCS terminal window |
